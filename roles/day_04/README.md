День 4. Работа с файлами и правами доступа

Что изучил и реализовал:

Разобрался с настройкой владельца файлов и директорий через owner.
Изучил права доступа Linux (chmod) и их применение через параметр mode.
Разобрался с параметрами path, state, dest и content.
Закрепил принцип идемпотентности Ansible: повторный запуск не должен изменять систему, если она уже соответствует заданному состоянию.

Практика:

Автоматизировал создание директории /var/log/my_app с правами 0700 и развёртывание лог-файла app.log с правами 0640, владельцем bubu и заданным содержимым.

Результат: научился автоматизировать создание файловой структуры и управление правами доступа на Linux-сервере средствами Ansible.
