# Ansible 30-Days Challenge | DevOps Песочница

Мой личный челлендж по изучению и автоматизации инфраструктуры с помощью **Ansible** и **Terraform**. Каждый день — новая практическая задача, от управления пакетами до деплоя полноценных приложений в Docker под прикрытием Nginx с SSL.

## Прогресс челленджа

### Неделя 1: Базовый синтаксис и основы Linux
*   [x] **День 1:** Настройка окружения. Установка Ansible, конфигурация `hosts.ini` и первый пинг (`ansible all -m ping`).
*   [x] **День 2:** Управление пакетами. Установка последних версий `curl`, `git`, `htop` через модули пакетных менеджеров.
*   [x] **День 3:** Настройка SSH. Автоматическое копирование публичного SSH-ключа на удаленный сервер в `authorized_keys`.
*   [ ] **День 4:** Работа с файлами и правами. Создание структуры папок, выставление безопасных прав `0700` и деплой лог-файлов.
*   [ ] **День 5:** Таймауты и Cron. Автоматизация очистки временных директорий каждые 15 минут через системный планировщик.
*   [ ] **День 6:** Скачивание и архивация. Загрузка архивов с внешних ресурсов и их распаковка в директорию `/opt/`.
*   [ ] **День 7:** Итоговый плейбук недели. Сборка единого сценария для настройки «чистого» сервера с нуля.

### Неделя 2: Конфигурации, Шаблоны и Хендлеры 
*   [ ] **День 8:** Замена строк (`lineinfile`). Тюнинг конфигурации SSH-демона и запрет прямого входа под Root.
*   [ ] **День 9:** Блоки текста (`blockinfile`). Инъекция кастомных bash-алиасов в конфигурационные файлы пользователей.
*   [ ] **День 10:** Базовый Jinja2. Создание динамического шаблона приветствия `MOTD` с выводом фактов об операционной системе и железе.
*   [ ] **День 11:** Циклы (`loop`). Оптимизация тасок для массового создания директорий с уникальными правами доступа.
*   [ ] **День 12:** Сложные Хендлеры. Изменение настроек системного логгера с валидацией синтаксиса перед перезапуском службы.
*   [ ] **День 13:** Условия (`when`). Кроссплатформенность: динамический выбор пакетного менеджера (`apt`/`dnf`) в зависимости от дистрибутива.
*   [ ] **День 14:** Итоговая Роль. Сборка комплексной роли `system_tune` для базовой оптимизации и безопасности ОС.

### Неделя 3: Docker, Секреты и Работа с Данными 
*   [ ] **День 15:** Установка Docker. Подключение официальных репозиториев, установка Docker Engine и запуск демона.
*   [ ] **День 16:** Ansible Vault (База). Шифрование чувствительных данных (паролей БД) и их расшифровка на лету в рантайме.
*   [ ] **День 17:** Одиночный контейнер. Развертывание изолированной базы данных PostgreSQL с прокидыванием секретов из Vault.
*   [ ] **День 18:** Копирование Docker Compose. Генерация конфигураций `docker-compose.yml` на основе Jinja2-шаблонов.
*   [ ] **День 19:** Запуск Docker Compose. Автоматический подъем мультиконтейнерных приложений через модуль `docker_compose_v2`.
*   [ ] **День 20:** Очистка Docker. Написание таски-дворника для удаления неиспользуемых образов, сетей и остановленных контейнеров.
*   [ ] **День 21:** Итоговый деплой. Написание роли для связки бэкенд + БД, изолированных внутри внутренней сети Docker.

### Неделя 4: Сеть, Безопасность и Отказоустойчивость 
*   [ ] **День 22:** Брандмауэр (UFW). Настройка сетевого экрана: жесткое закрытие всех портов, кроме веб-трафика и кастомного SSH.
*   [ ] **День 23:** Генерация SSL. Автоматизация выпуска самоподписанных сертификатов безопасности для локальных сервисов.
*   [ ] **День 24:** Nginx HTTPS. Модернизация шаблонов веб-сервера для проксирования трафика в Docker по защищенному протоколу.
*   [ ] **День 25:** Автоматический Бэкап. Создание дампов баз данных из контейнеров, их архивация по датам и скачивание на локальную машину.
*   [ ] **День 26:** Обработка ошибок (`block/rescue`). Реализация отказоустойчивости плейбуков: автоматический откат при сбоях деплоя.
*   [ ] **День 27:** Переменные окружения (`.env`). Динамическая сборка файлов окружения для приложений из различных источников данных.
*   [ ] **День 28:** Сборка многоэтапного плейбука. Создание мастер-плейбука `site.yml`, оркеструющего цепочку ролей.
*   [ ] **День 29:** Оптимизация скорости. Настройка асинхронного выполнения тяжелых тасок и включение SSH-pipelining.
*   [ ] **День 30:** Финальный Босс. Развертывание инфраструктуры с нуля: от голого Linux до защищенного HTTPS веб-узла с бэкапами и мониторингом.

---

## 🛠️ Стек технологий
*   **Automation:** Ansible (Roles, Templates, Vault, Handlers)
*   **Containerization:** Docker, Docker Compose
*   **Web & Security:** Nginx, UFW, SSL, Crontab

## 🚀 Как запустить плейбуки локально
```bash
# Проверка синтаксиса плейбука
ansible-playbook playbook.yml --syntax-check

# Запуск плейбука на группу хостов
ansible-playbook -i hosts.ini playbook.yml
```
